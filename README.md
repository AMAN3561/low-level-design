# Low-Level Design (LLD)

A collection of Low-Level Design concepts, SOLID principles, design patterns, and practical LLD examples implemented primarily in C++.

## 📚 Topics Covered

### SOLID Principles
- Single Responsibility Principle
- Open/Closed Principle
- Liskov Substitution Principle
- Interface Segregation Principle
- Dependency Inversion Principle

### Design Patterns
- Strategy Pattern
- Factory Pattern
- Abstract Factory Pattern
- Singleton Pattern
- Observer Pattern
- Decorator Pattern
- Adapter Pattern
- Command Pattern
- Facade Pattern

## 🏗️ LLD Projects
- Document Editor
- Notification System
- Zomato Design

## 💻 Language
- C++

## 🎯 Goal

This repository documents my journey of learning object-oriented design, design patterns, and Low-Level Design for software engineering interviews and real-world development.
